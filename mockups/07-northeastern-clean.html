Getting Started

Set up in under a minute.

No account needed. No configuration. Install, upload, analyze.

1

Install the extension

Add from Chrome Web Store. Only NUWorks page permissions required.

2

Upload your resume

Paste text or upload a PDF. Skills extracted locally in milliseconds.

3

Analyze postings

Open NUWorks, click the extension, hit Analyze. Results appear in real time.
